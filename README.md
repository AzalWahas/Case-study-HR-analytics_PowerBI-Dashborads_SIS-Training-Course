# Case-study-HR-analytics_PowerBI-Dashborads_SIS-Training-Course

Overview
This repository contains the source code and structural components for a comprehensive Power BI analytics dashboard. The project is structured using modern Power BI report architecture, incorporating modular page layouts, custom visual configurations, theme definitions, and an underlying semantic data model.
 Key Features & ComponentsMulti-Page Analytical Layout: Built with multiple dedicated report pages containing customized visuals (clustered charts, matrices, KPI cards, and slicers).Theming & Styling: Utilizes custom JSON theme configurations (such as Charcoal & Lime and Fluent2) to ensure consistent corporate branding and high-contrast accessibility.  Rich Visual Assets: Includes custom icon registries and static resource mappings (such as attrition tracking icons and dynamic filter assets).  Robust Data Model: Houses optimized relationships, measures, and data structures tailored for high-performance enterprise reporting.🚀 Getting Started / DeploymentTo open, edit, or deploy this dashboard from the source code:Prerequisites:Download and install Microsoft Power BI Desktop.Opening the Project:Clone or extract this repository to your local machine.Depending on how your workspace packages the source files, you can open the root folder via Power BI Desktop or re-pack the contents into a .pbip (Power BI Project) or .pbix format.Data Source Configuration:Navigate to Transform Data (Power Query) in Power BI Desktop to update your data source connection strings (SQL Server, cloud sources, or local files) to match your environment.Publishing:Once connected and refreshed, click Publish in Power BI Desktop to upload the report to your designated Power BI Service Workspace.
